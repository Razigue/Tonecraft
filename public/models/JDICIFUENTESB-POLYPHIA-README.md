# jdicifuentesb — Polyphia

`polyphia-so-strange.nam` is the unmodified A2 download of **So Strange**,
model 397730, from the **Polyphia** tone by **jdicifuentesb**.

Source: https://www.tone3000.com/tones/polyphia-49731

Download: https://api.tone3000.com/storage/v1/object/public/models/vxpp8fwrft_a2.nam

An amp + cab capture of a Polyphia clean tone, tested with humbuckers. The
pack holds 14 models; Tonecraft ships only So Strange. The author asks for no
IR, so the Polyphia preset selects the `none` cabinet (a unit impulse), and for
chorus, delay and reverb after it: Tonecraft has only the reverb, which Polyphia
turns on at 15 %. The original SlimmableContainer includes A2-Full and A2-Lite;
Tonecraft uses the default full model.
